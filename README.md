# 🍜 CYBER RAMEN: Night Yatai 3D

> **First-Person 3D Cyberpunk Street Ramen Simulator** — мобильная WebGL-игра от первого лица для **Telegram Mini Apps (TMA)** и **iOS / Android PWA**, написанная на чистом JavaScript (Vanilla ES Modules + Custom WebGL 3D Engine + Procedural Web Audio API) без единой внешней библиотеки.

---

## ✨ Ключевые особенности (Beta)

- **Полноценный 3D-движок от первого лица на чистом WebGL (`js/webgl3d.js`):**
  - Процедурная генерация 3D-геометрии (`Lathe`-вращение керамических мисок Донбури и стальных чанов Зундо-набэ, волнистая 3D-лапша, сетчатые сотейники «Тэбо», картонные вок-коробочки с 4 складывающимися клапанами, 3D-топпинги и курьерский квадрокоптер CyberEats).
  - Кастомные GLSL-шейдеры с направленным освещением, бликами (`specular`), атмосферным неоновым туманом дождливого переулка и процедурными текстурами (мраморная свинина Тяшу, волокна Нори, капли жира на поверхности бульона, орнамент керамики).
  - **Адаптивный Hor+ FOV** — камера автоматически подстраивает угол обзора под соотношение сторон любого смартфона (`19.5:9`, `20:9`, `16:9`), планшета или десктопа.
- **360° Кухня раменной тележки (3 сектора со свайп-навигацией):**
  - **⬅️ Сектор 0 (Варочный цех):** японский бойлер «Юдэмэнки» на 3 сетчатых сотейника «Тэбо» и 3 кипящих котла «Зундо-набэ» на газово-плазменных конфорках (*Тонкоцу*, *Острый Чили*, *Неон-Мисо*).
  - **⬆️ Сектор 1 (Сборка, прилавок и гости):** 2 ряда стальных гастроемкостей с 6 видами 3D-топпингов (*маринованное яйцо Аджитама, свинина Тяшу, листы Нори, зелёный лук, креветка Темпура, острый соус Чили*), 3 слота на столе для временной постановки и переливания блюд, подстольная мусорка, неоновый котик «Манэки-нэко» и анимированные 2.5D-гости с голосовой озвучкой заказов.
  - **➡️ Сектор 2 (Склад и дрон-доставка CyberEats):** диспенсеры керамических мисок и открытых картонных вок-коробок, крио-холодильник со стеклянной витриной для пополнения запасов и парящий курьерский дрон CyberEats.
- **Живая механика левой и правой рук повара:**
  - Взятая миска или вок-коробка всегда находится в **левой руке** героя при перемещении между секторами.
  - На центральном столе можно временно разместить до **3 блюд**, взять их обратно в руку или **перелить содержимое** из миски в вок-коробку (и наоборот) — после переливания пустая посуда автоматически убирается со стола.
  - **3-шаговая варка лапши в сотейнике «Тэбо»:**
    1. *1-й тап* — опустить сотейник с сырой лапшой в кипящую воду (запускается тикающий таймер).
    2. *2-й тап* — поднять сотейник из кипятка, зафиксировав проварку (`Al Dente`, `недовар` или `перевар`) без немедленного сброса в миску (можно сварить и поднять все 3 сотейника впрок).
    3. *3-й тап* — правая рука делает встряхивание воды «Югири» и поворотом против часовой стрелки высыпает каскад лапши в подставленную левой рукой миску или вок-коробку.
  - **Авто-закрывание вок-коробки и отправка дрону:** тап по курьерскому дрону автоматически складывает 4 картонных клапана вок-коробки, запечатывает её неоновой пломбой и отправляет заказ по воздуху.
- **Готовность к Telegram Mini App (`Telegram ID` + `CloudStorage`):**
  - Автоматическое определение запуска внутри Telegram (`window.Telegram.WebApp`), раскрытие на весь экран (`expand()`), блокировка случайного закрытия при вертикальных свайпах (`disableVerticalSwipes()`).
  - Привязка профиля и сохранений к уникальному `Telegram ID` игрока (`CR_NIGHT_YATAI_SAVE_V1_TG_<user.id>`) с синхронизацией через `Telegram.WebApp.CloudStorage`.

## 🎮 Управление

| Действие | Жест / Тап |
| :--- | :--- |
| **Поворот между секторами (Варка ⇄ Стол ⇄ Склад)** | Горизонтальный свайп влево / вправо |
| **Посмотреть на покупателя / вернуться на стол** | Вертикальный свайп в центральном секторе |
| **Взять миску или вок-коробку в левую руку** | Тап по стопке мисок или коробок в правом секторе |
| **Опустить лапшу → Поднять из воды → Высыпать в посуду** | 1-й тап → 2-й тап → 3-й тап по сотейнику в левом секторе |
| **Налить бульон поварёшкой** | Тап по нужному чану с бульоном в левом секторе |
| **Добавить топпинг / полить соусом Чили** | Тап по гастроемкости в центральном секторе |
| **Поставить посуду на стол / Взять со стола** | Тап по одному из 3 мест на переднем крае центрального стола |
| **Перелить из миски в коробку (или наоборот)** | Держа посуду в руке, тапнуть по посуде, стоящей на столе |
| **Отдать заказ покупателю** | Свайпнуть на клиента и тапнуть на него |
| **Отправить доставку CyberEats** | Тапнуть по курьерскому дрону с наполненной вок-коробкой в руке |
| **Выбросить испорченное блюдо из руки** | Тапнуть по мусорному баку слева под столом |

## 🗂️ Структура проекта

```text
cyber-ramen/
├── index.html          # Точка входа, HUD, диалоги финансового терминала и кодекса, подключение Telegram WebApp SDK
├── manifest.json       # Web App Manifest для установки PWA на iOS / Android
├── sw.js               # Service Worker для офлайн-кеширования ассетов
├── vercel.json         # Конфигурация заголовков и роутинга для Vercel
├── icon.svg            # Векторная неоновая иконка игры
├── css/
│   ├── main.css        # Адаптивная дизайн-система, HUD, Safe Area, модальные окна
│   └── sectors.css     # Полноэкранный 3D-вьюпорт и голографические метки
└── js/
    ├── main.js         # Главный цикл приложения, связка 3D-сцены, кухни, гостей и экономики
    ├── webgl3d.js      # Кастомный 3D-движок на WebGL (шейдеры, процедурные меши, камера, анимации рук)
    ├── art3d.js        # Генератор процедурных текстур киберпанк-переулка, вывесок и 2.5D-аниме гостей
    ├── kitchen.js      # Логика готовки, 3 слота стола, переливание, свежесть блюд, мусорка и доставка
    ├── customers.js    # Генерация заказов (включая заказы «с собой»), очередь, оценка точности и отзывы
    ├── economy.js      # Финансовый терминал смены, аренда, кредиты «Арасака», коллектор и апгрейды
    ├── audio.js        # Процедурный синтезатор звука на Web Audio API (бульон, свист чайника, таймер, голос, синтвейв)
    ├── state.js        # Менеджер состояния, интеграция с Telegram ID и Telegram CloudStorage
    ├── config.js       # Баланс экономики, рецепты меню, топпинги, районы и апгрейды
    ├── renderer.js     # Вспомогательные SVG-генераторы
    └── tutorial.js     # Ненавязчивая система прогрессии первого дня
```

## 🚀 Быстрый запуск локально

Проект не требует сборки или установки `node_modules` — достаточно любого статического HTTP-сервера:

```bash
python3 -m http.server 8080
```

После запуска открой в браузере: `http://localhost:8080`

## ☁️ Деплой на Vercel и подключение Telegram Mini App

1. **Vercel:**
   - Импортируй репозиторий `edmuundoo/cyber-ramen` в [Vercel](https://vercel.com/new) (Framework Preset: **Other**, Build Command: *пусто*, Output Directory: `.`).
   - Нажми **Deploy** — игра мгновенно станет доступна по HTTPS-ссылке вида `https://cyber-ramen.vercel.app`.
2. **Telegram Mini App (`@BotFather`):**
   - В [@BotFather](https://t.me/BotFather) создай бота (`/newbot`) или выбери существующего (`/mybots`).
   - Перейди в **Bot Settings → Menu Button → Configure menu button** и укажи свой HTTPS URL с Vercel.
   - При открытии внутри Telegram игра автоматически развернётся на весь экран и привяжет сохранение к `Telegram ID` пользователя.
